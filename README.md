# memo.react

Reactで作成する簡易メモアプリのひな形です。

## 手順

### 準備

#### 1. 本リポジトリをクローンする

本リポジトリをローカル環境にクローンしてください。

#### 2. ブランチを作成して切り替える

以下のコマンドを実行し、自分の学生番号をブランチ名としてブランチを作成してください。

```bash
git switch -c <学生番号>
```

例：

```bash
git switch -c t26001
```

#### 3. 必要なパッケージをインストールする

以下のコマンドを実行してください。

```bash
npm install
```

#### 4. 開発サーバーを起動する

以下のコマンドを実行してください。

```bash
npm run dev
```

開発サーバーが起動したら、ブラウザから以下のURLにアクセスしてください。

```text
http://localhost:5173
```

## ひな形の構成

```text
memo.react.tl/
├── index.html
├── package.json
└── src/
    ├── main.tsx          ← 変更不要
    ├── index.css         ← 変更不要
    ├── App.tsx           ← ここに処理を書いていく
    └── App.module.css    ← スタイル（自由にアレンジしてかまいません）
```

`src/App.tsx` には完成イメージのJSXだけが書かれています。`useState` と `map()` を使って、動くメモアプリに書き換えてください。`src/App.module.css` には、以下の機能で使うクラス（エラー表示用の `.error` など）があらかじめ用意されています。

## 実装

以下の機能を実装してください。

### 基本機能

#### 1. メモの入力

テキストフィールドにメモを入力できるようにしてください（制御コンポーネント）。

#### 2. メモの追加

「追加」ボタンをクリックすると、入力した内容がメモ一覧に追加されるようにしてください。

追加された各メモには「削除」ボタンを表示してください。

#### 3. メモの削除

「削除」ボタンをクリックすると、対象のメモがメモ一覧から削除されるようにしてください。

### 追加機能

#### 4. Enterキーで追加

入力欄でEnterキーを押しても追加できるようにしてください。日本語の変換を確定するEnterでは追加されないようにしてください。

#### 5. 作成日時の表示

各メモに、追加した日時を表示してください。

#### 6. 入力チェック

空のまま追加しようとしたら、入力欄を赤枠にし、「メモを入力してください」とエラーメッセージを表示してください。入力を始めたらエラー表示を消してください。

#### 7. 件数表示

「メモ一覧（3件）」のようにメモの件数を表示してください。0件のときは「メモはまだありません」と表示してください。

#### 8. 編集機能

各メモに「編集」ボタンを表示してください。クリックするとそのメモが入力欄に切り替わり、「保存」で内容を更新、「キャンセル」で元に戻るようにしてください。

## 提出

### 1. GitHubにpushする

実装が完了したら、以下のコマンドを実行し、自分のブランチをGitHubにpushしてください。

```bash
git push origin <学生番号>
```

例：

```bash
git push origin t26001
```

# memo.react

Reactで作成する簡易メモアプリのひな形です。

## 手順

### 準備

#### 1. 本リポジトリをクローンする

本リポジトリをローカル環境にクローンしてください。

#### 2. ブランチを作成して切り替える

以下のコマンドを実行し、自分の学生番号をブランチ名としてブランチを作成してください。

```bash
git switch -c <学生番号>
```

例：

```bash
git switch -c t26001
```

#### 3. 必要なパッケージをインストールする

以下のコマンドを実行してください。

```bash
npm install
```

#### 4. 開発サーバーを起動する

以下のコマンドを実行してください。

```bash
npm start
```

開発サーバーが起動したら、ブラウザから以下のURLにアクセスしてください。

```text
http://localhost:3000
```

## 実装

以下の機能を実装してください。

### 1. メモの入力

テキストフィールドにメモを入力できるようにしてください。

### 2. メモの追加

「追加」ボタンをクリックすると、入力した内容がメモ一覧に追加されるようにしてください。

追加された各メモには「削除」ボタンを表示してください。

### 3. メモの削除

「削除」ボタンをクリックすると、対象のメモがメモ一覧から削除されるようにしてください。

## 提出

### 1. GitHubにpushする

実装が完了したら、以下のコマンドを実行し、自分のブランチをGitHubにpushしてください。

```bash
git push origin <学生番号>
```

例：

```bash
git push origin t26001
```
